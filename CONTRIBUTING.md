# Contributing to FiatLux

Thank you for your interest in contributing to **FiatLux**! Contributions of all kinds are welcome, whether it's fixing a bug, improving the DSL, adding features, or improving documentation.

## Getting Started

### 1. Fork the Repository

Fork the FiatLux repository to your own GitHub account.

Then clone your fork:

```bash
git clone https://github.com/d3nzus/fiatlux
cd fiatlux
```

### 2. Create a Branch

Create a separate branch for your changes. Avoid making changes directly on `main`.

```bash
git checkout -b feature/my-feature
```

Use a descriptive branch name, such as:

```text
feature/add-templates
fix/parser-error
docs/update-dsl
```

### 3. Make Your Changes

Make your changes and test them locally before submitting them.

For Rust development, you can build and test the project with:

```bash
cargo build
cargo test
```

Please keep changes focused on the purpose of your branch.

### 4. Commit Your Changes

Commit your changes with a clear commit message:

```bash
git add .
git commit -m "Add template support"
```

### 5. Push to Your Fork

Push your branch to your fork:

```bash
git push origin feature/my-feature
```

Your changes should be pushed to **your fork**, not directly to the main FiatLux repository.

### 6. Open a Pull Request

On GitHub, open a **Pull Request** from your fork and branch to the `main` branch of FiatLux.

In your pull request, briefly describe:

* What you changed
* Why you changed it
* Any relevant issues or discussions
* How you tested your changes

## Reporting Issues

Found a bug or have an idea for FiatLux? Open an issue on the repository.

When reporting a bug, include:

* A description of the problem
* Steps to reproduce it
* Expected behavior
* Actual behavior
* Relevant Blueprint code or error messages

## Code of Conduct

Please be respectful and constructive when contributing. FiatLux is an open-source project, and everyone should be able to participate in a welcoming environment.

Thank you for helping make **FiatLux** better!
